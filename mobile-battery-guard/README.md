# Mobile Battery Guard v1.0.1 – by Digital Arts

फ़ोन की बैटरी की उम्र बढ़ाने वाला मुफ़्त Android ऐप। *Made with ♥ in Andaman.*

A free Android app that reminds you to unplug the charger at 80% and plug it in at 20%, so your phone battery lasts longer.

## ⬇️ डाउनलोड / Download

**[MobileBatteryGuard.apk डाउनलोड करें](https://github.com/datplindia/digital-toolbox-updates/raw/main/mobile-battery-guard/MobileBatteryGuard.apk)**: Android 7.0 या नया फ़ोन, लगभग 110 KB।

## फ़ीचर / Features

- बैटरी **80%** पर नोटिफ़िकेशन, आवाज़ और वाइब्रेशन: "चार्जर निकाल दें"। **20%** पर: "चार्जर लगाएँ"।
- चार्जर निकालते या लगाते ही अलार्म अपने-आप बंद।
- अलार्म अनदेखा करें तो कुछ मिनट बाद फिर याद दिलाता है। "इस बार याद न दिलाएँ" और "1 घंटे के लिए रोकें" के विकल्प भी हैं।
- नोटिफ़िकेशन बार में बैटरी % हमेशा दिखता है, और फ़ोन चालू होते ही ऐप अपने-आप शुरू हो जाता है।
- बैटरी हेल्थ (जहाँ फ़ोन बताता है): क्षमता, तापमान, वोल्टेज, करंट, चार्ज साइकल।
- **हिंदी / English** टॉगल।

## इंस्टॉल कैसे करें / How to install

1. ऊपर के लिंक से APK डाउनलोड करें और फ़ाइल पर टैप करें।
2. "Install unknown apps" पूछे तो उस ऐप (Chrome / WhatsApp / File Manager) के लिए **Allow** करें।
3. Play Protect पूछे तो **More details → Install anyway** दबाएँ। ऐप Play Store पर नहीं है, इसलिए यह चेतावनी आती है।
4. ऐप खोलें और नोटिफ़िकेशन की अनुमति दें।
5. पीला बॉक्स दिखे तो "ऑप्टिमाइज़ेशन हटाएँ" दबाएँ।

**Xiaomi / Redmi / POCO / Oppo / Vivo / Realme:** इन फ़ोन में Settings → Apps → Mobile Battery Guard में **Autostart** चालू करें, और Battery saver को **No restrictions** पर रखें।
