# DA Pay Alert

Live payment dashboard for the office, plus the Android app that sends payments from the QR / bank-SMS phone.

- **Dashboard (office computer):** https://raw.githack.com/datplindia/digital-toolbox-updates/main/pay-alert/index.html
- **Android app (v1.3.0):** [DAPayAlert.apk](https://github.com/datplindia/digital-toolbox-updates/raw/main/pay-alert/DAPayAlert.apk)

The dashboard opens only on devices approved by the owner (Settings → Approved devices, with the owner code).
No codes or passwords are stored in this repository.
